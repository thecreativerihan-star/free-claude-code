Outbound proxies

Precedence: PROXY_URL → dashboard → ALL_PROXY → HTTPS_PROXY → HTTP_PROXY → system → direct.

PROXY_MODEforwardforward (HTTP/SOCKS) ya fetch-relay. fetch-relay me URL https hona chahiye.
PROXY_URLunsetOutbound proxy. Schemes: http, https, socks4, socks4a, socks5, socks5h.
FETCH_RELAY_TOKENunset (unauthenticated)Relay bearer credential. Dashboard se save karne par encrypt; env var DB me nahi jata.
ALL_PROXY / HTTPS_PROXY / HTTP_PROXYunsetStandard proxy variables (lower-case bhi). NO_PROXY se bypass.
NO_PROXYunsetDirect reach wale hosts. Bare domain = subdomains; * = proxy off.
PROXY_REQUIRED_PLATFORMSunsetFail-closed: listed platforms ko proxy zaroori, warna explicit error.
FREEAPI_PROXY_LOCAL_DESTINATIONSfalsetrue = localhost/LAN (Ollama, LM Studio) bhi proxy se. Default me bypass.
